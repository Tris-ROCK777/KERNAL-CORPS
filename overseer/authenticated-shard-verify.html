Overseer authenticated shard acceptance

This is an isolated browser test. It creates a temporary test authority key, signs a 32 KiB test shard, verifies the signature before OPFS write, and checks the stored bytes by reading them back. It does not enroll or replace the production authority key.

Security boundary: the test's public key is generated locally only to test the code path. Production use requires a separately provisioned, independently pinned authority public key.
